# Aura Website

This project is a small creative website that plays with the idea that every person has an "aura" — a mood, a color, a presence.

Instead of focusing on complex features, the goal was to build an experience.
Something visual and interactive that feels alive when you open it.

---

## What it does

The website reacts visually to the user and presents different moods through colors, motion, and layout.

Think of it as a digital personality space rather than a traditional website.

---

## Why I made it

I wanted to experiment with design emotion, not just structure.

Most projects focus on functionality.
This one focuses on *feeling*:

- how colors affect perception
- how motion changes attention
- how small interactions make a page feel human

---

## Built with

- HTML
- CSS
- JavaScript

No frameworks — just core web fundamentals.

---

## What I learned

While building this, I practiced:

- translating ideas into visuals
- balancing animation and readability
- designing atmosphere, not just layout
- making interaction feel natural
