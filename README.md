# Aura Vision Board Web App

A multi-page interactive productivity web application that helps users visualize goals, track quests, and plan monthly & yearly progress.

## ✨ Features
- Vision board page
- Monthly calendar
- Yearly roadmap
- Quest tracker
- Sign-in system (UI)
- Responsive design

## 🛠 Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
